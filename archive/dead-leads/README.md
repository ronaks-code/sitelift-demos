# Retired demos

Demos taken offline because the lead is dead. Each zip holds the folder as it was; unzip at the repo root to restore it.

**Reusing a design (Vinay 2026-11-11):** a dead lead's design is free to reuse for the next business in the same trade.
The factory's kit picker (`factory/tools/pick_kit.py`) no longer counts `dropped` or `not_interested` leads, so their kit
can go to a nearby shop again. To start from a saved site instead, unzip it, copy the folder to the new
`<industry>/<state>/<slug>/` and swap in the new business's name, photos, hours, services and reviews. Never reuse their
own name, photos or reviews, and never show a saved design back to the business it was made for.
